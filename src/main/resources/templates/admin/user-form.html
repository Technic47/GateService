Доступ к сервисам

Сервисов пока нет. Добавить сервис.

Поле справа — роль пользователя внутри приложения (claim roles в токене Gate Auth), например admin. Работает только при выданном доступе; пусто — без роли. Сервисам без библиотеки gate-auth не нужна.
Администратор по умолчанию имеет доступ ко всем сервисам независимо от этих галочек — это поведение отключается на странице настроек гейта.
