Сервис

← ко всем сервисам

Строчная латиница, цифры, дефис, подчёркивание. Ровно это значение Nginx передаёт в заголовке X-Service-Name — при расхождении гейт ответит 403 «неизвестный сервис».
Показывается пользователю на плитке в портале.

Куда проксировать (upstream)

Адрес с точки зрения VPS. Для сервиса за reverse SSH-туннелем это локальный конец туннеля — https://127.0.0.1:8080, а не адрес домашнего сервера.

Куда отправлять браузер

Адрес, по которому сервис открывается снаружи — через Nginx с проверкой гейта. Именно сюда ведёт плитка в портале. Если оставить пустым, гейт подставит upstream, и переход не сработает.
