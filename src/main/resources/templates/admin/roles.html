Роли приложений

Роли, которые гейт выдаёт приложениям (claim roles в токене Gate Auth). Глобальная роль доступна в каждом сервисе; роль сервиса — только в нём. Выдаются на странице пользователя, по сервисам, по нескольку. Приложения сами получают свой список и решают, что роль разрешает: новая роль ничего не даёт, пока её не настроят в приложении.

Добавить роль Версия каталога: 1 — растёт при каждом изменении, приложения по ней понимают, что пора обновить список.
Код Название Где действует Выдана Состояние Действия
editor Редактор
глобальная Сервис 0 раз активна Изменить
Ролей пока нет. Добавьте глобальные (например viewer, admin) или роли конкретного сервиса.
